# Data Availability

The dissertation uses four publicly available datasets: EdNet KT4 and ASSISTments for educational recommendation, and RetailRocket and Amazon Electronics for e-commerce recommendation.

The raw datasets are not redistributed in this reproducibility package. They remain subject to the access conditions, licences and terms of their respective providers. This repository archives the executed computational notebooks, experimental workflow documentation and reproducibility metadata supporting the dissertation.

## Dataset-level provenance
- **EdNet KT4:** educational sequential recommendation experiment.
- **ASSISTments:** educational sequential recommendation experiment.
- **RetailRocket:** implicit-feedback e-commerce sequential recommendation experiment.
- **Amazon Electronics:** e-commerce sequential recommendation experiment.

The authoritative access location and bibliographic citation for the exact release of each source dataset should be retained in the dissertation and repository metadata. Raw source data should not be redistributed here unless its original licence explicitly permits redistribution.

## Dissertation Data Availability Statement
> The empirical analyses reported in this dissertation use four publicly available datasets: EdNet KT4 and ASSISTments for educational recommendation, and RetailRocket and Amazon Electronics for e-commerce recommendation. The original datasets remain subject to the access conditions and licences of their respective providers and are therefore not redistributed as part of this dissertation reproducibility package. The executed experimental notebooks, workflow documentation and reproducibility metadata supporting the four experiments are archived in a public GitHub repository at https://github.com/namabossu/leakage-aware-cross-domain-sequential-recommendation. A versioned archival snapshot of the complete reproducibility package is deposited in Zenodo and is persistently identified by DOI 10.5281/zenodo.23199215. Dataset-specific provenance, preprocessing procedures and experimental configurations are documented in the repository and dissertation.
