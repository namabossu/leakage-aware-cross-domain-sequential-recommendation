# Data Availability

The dissertation uses four publicly available datasets: EdNet KT4 and ASSISTments for educational recommendation, and RetailRocket and Amazon Electronics for e-commerce recommendation.

The raw datasets are not redistributed in this reproducibility package. They remain subject to the access conditions, licences and terms of their respective providers. The repository archives the executed computational notebooks, workflow documentation and reproducibility metadata supporting the dissertation experiments.

## Dissertation Data Availability Statement

> The empirical analyses reported in this dissertation use four publicly available datasets: EdNet KT4 and ASSISTments for educational recommendation, and RetailRocket and Amazon Electronics for e-commerce recommendation. The original datasets remain subject to the access conditions and licences of their respective providers and are therefore not redistributed as part of this dissertation reproducibility package. The executed experimental notebooks, workflow documentation and reproducibility metadata supporting the four experiments are archived in a public GitHub repository. A versioned archival snapshot of the complete reproducibility package is deposited in Zenodo and assigned a persistent Digital Object Identifier (DOI). Dataset-specific provenance, access conditions, preprocessing procedures and experimental configurations are documented in the repository and dissertation.
